# RIG Memory OS

Use `rig-memory-os call <tool> --input '<json>'` or the registered
`rig_memory_os`/`rig-memory-os` MCP server. Always provide `tenant_id`, operator,
purpose, hierarchy scope, and sensitivity ceiling. Record observed events as
events; propose model output as a candidate. Predictions may only prefetch,
warm, load, prepare, or alert. They never authorize canonical writes, sends,
merges, deletion, spend, or completion.

Knowledge promotion writes to JakeStudio Obsidian first. gBrain is a derived
index. Never store raw secrets; use secret references.
